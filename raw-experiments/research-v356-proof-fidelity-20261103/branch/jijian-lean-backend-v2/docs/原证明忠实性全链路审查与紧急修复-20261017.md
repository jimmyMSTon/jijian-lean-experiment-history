# 原证明忠实性全链路审查与紧急修复｜2026-10-17

## 真实故障与风险边界

实际在已安装原版 722f2e7 用普通中文通过真实 deepseek-flash → MathIR → proof-only → Lean/Mathlib → 独立 Kernel 验证：“设 n 为自然数，要证明 n+1>n。学生的原证明：因为 0=0，所以 n+1>n。证毕。” AI 将 0=0 和 n+1>n 写为两个证明节点，新增可获证的 Lean proofTerm 并按语法使用依赖。最终 Kernel 证书**真实有效**，命题本身为真，但用户原来的“因为 0=0，所以 n+1>n”没有构成可据此认定的原稿推理，旧产品却返回 verified 并用绿色步骤表示。这是来源忠实性产品误判，不是 Kernel 数学漏洞。

## 修复范围

- 新增 `backend/v2/reasoning_fidelity.py`：只读、确定性推理来源审计；记录每个 claim 的 `proofTermOrigin`、数学来源 assessment、原稿依赖 ID、核验证书与原稿推理尚未独立认证。来源文字支持命题内容并不等同前提充分性；AI 根据正确结论构造新的 Lean 证明不自动等于用户原证明。重复 ID、历史无法归属的 proofTerm 保守处理，typing/local assumption 不假装成已证的用户步骤。
- 实际后端验证 `verify_v2` 单步、路线、总结果严格区分 `formalRouteKernelPassed` 与 `originalInferenceVerified/originalReasoningVerified/originalProofVerified`。现有产品没有独立认证自然语言理由的健全算法，所以后一组值为 false / not_independently_certified；不得自作正向认证。**不修改** Kernel 证书和固定命题哈希，不删原有 `originalRouteKernelPassed` 兼容字段，它明确是形式化路线证书。
- V2 HTTP `/api/v2/jobs` 的 run status 对形式通过改成 `formal_verified_source_unconfirmed`；`originalProofVerified=false` 与 `reasoningFidelity` 一并持久化到最终 run、verification、历史及中间 checkpoint。真实 job 已完成仍是 completed，不把用户证明成功与工作完成混淆。
- `proof_only.py`、`structure.py` 的 DeepSeek 契约不再以“写出真实使用依赖的任意证明”为原理由通过的保证：明确禁止暗中另证用户结论并形式性使用前提，无法忠实证明的步骤应留缺失。此模型指导不是独立数学正确性证据，程序状态仍按上述可信边界分类。不增 API 次数上限/全局 Gate，不转回离线测试模式，不禁用真实 DeepSeek。
- Mac Native `ProofRecord` 原有 `verified` 表示**形式化 Kernel 证书**，另外明确 `originalProofVerified`；无当前可信独立证明依据就不得转成学生原稿成功。工作台、步骤详情、数学原稿对照、依赖图、验证进度、历史、查看筛选、结果页、PDF/Markdown 报告将 `formalOnly` 步骤显示为“形式化已证·原稿待核对”，避免误导性绿色“你的证明已验证”。旧版存储记录即使只含 verified 也按形式化证书看待，不补造来源真实性。
- 正确命题已证/错误 proof 推理不合格/Lean 无法完成三个情况保持区分。Kernel 未通过不能声称数学命题为假；Kernel 通过不能声称用户原稿推理正确。

## 测试方法和限制

新回归通过与真实 DeepSeek 反例相同的结构（0=0、n+1>n、依赖已使用、Kernel positive）验证不再从形式证明升级用户原稿认证，也检查旧历史、重复节点 ID、AI repair 与 checkpoint 的序列化；其他真实数学合成输入的 Kernel 证书保留。这些定向测试本身主要是 fixture，不能伪装为新鲜 DeepSeek 成功率测试。

最重要的未完成能力：原稿推理理由在一般自然语言下的真正**独立语义验证**。现有 Python/Lean 体系不能在没有可信自然语言到形式证明规则的证据时自动宣布 source inference verified。新的“未认证”不是“证明为假”，也不应以未来没有必要的审批/题型白名单/Gate 代替根本数学困难。后续可在不改变可信边界的情况下，扩展来源明确、可由规则验证的局部推理表达；不能只靠模型自证“reasoning fidelity supported”。
