# 极简 Lean｜MathIR V3 原证明全依赖追踪与闭合引理图

日期：2026-10-17。开发基线 276fe68，独立 Mac Native 工作树 codex/native-math-document-engine，从当前已存在的开放式 MathIR V3 客户端、Mathlib 常量审计、数学排版、长证明、精确原稿位置继续。

## 本次新增的真正功能

新增 NativeProofDependencyAudit.swift，依据已保存的 proofRoutes/nodes/scopes/sourceRefs/verification 而不是生成第二份数学证明，构造只读、区分普通 dependsOn 与 closedDependencies 闭合辅助引理的可追踪依赖图。支持 transitive 先行步骤追踪，多层局部作用域、缺失引用、重复节点 ID、重复路线 ID、前向步骤依赖、直接和跨节点循环、非法或循环 scope 分析。针对已保存 Verification 步骤 Kernel status 和整条原路线是否完整 Kernel verified 做独立来源检查；图关系可读不代表证明通过。

新增 NativeProofDependencyAuditView.swift，工作台、结果页与步骤详情共用可展开依赖审计：每条源路线、保存的普通前序/闭合辅助引理、原稿转录片段、作用域链、来源缺失提示、步骤级 Kernel 状态、前序传递链、步骤详情和原稿对应链接。图谱显示的是证据的读法，不推断用户未声明的数学类型、前提或新的全局公理。

现有 NativeProofReport 的 Markdown/PDF 导出一并补上闭合辅助引理、普通依赖、结构异常、路线/节点冲突信息，使分享出去的报告也保留复杂原证明真正的依赖结构，而不是丢失闭合引理这一关键语义。

验证：新增 tests/native_proof_dependency_audit.swift 真实 Swift executable 检查普通/闭合前序、transitive tracing、缺失、重复、前向、自环、互相循环和无效作用域；直接载入 repository committed 的 contracts/examples/mathir-v3-case-scopes.json 及 mathir-v3-linear-map.json 进行跨领域真实 JSON 契约回放，确认 5 步分类讨论/2 处闭合依赖、3 步线性映射、scope 正确且没有伪 Kernel 证据。已增加为 scripts/check_native_math_document.py 的独立检查，与现有 9 组原生回归共同执行。全 macos/Native/*.swift SwiftUI typecheck PASS；最终完整回归/提交合并进度以真实工具结果为准。

本轮不修改 MathIR Pydantic、DeepSeek 路由、Statement Lock、Lean/Kernel、Repair 或用户数据，明确不把客户端结构诊断误称数学错误。Codex 仍负责数学实体、类型/运算及真正的 Lean 验证扩建；新的 Mac 依赖追踪不阻断任何真实业务。
