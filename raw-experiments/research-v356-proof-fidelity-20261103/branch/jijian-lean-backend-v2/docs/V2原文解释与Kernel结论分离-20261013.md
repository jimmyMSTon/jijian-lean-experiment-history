## 通用改动

- ProofRecord.status 先根据固定形式化路线和真实 Kernel 状态定性，再同时保留全部来源解释警告，绝不把解释警告冒充数学验证失败。
- NativeStore.observe/openHistory 的 V2 展示分支依据已保存的真实 original-route Kernel 状态选择成功或未完成页面。V1 路由保持旧有逻辑。
- NativeResult 单独逐项展示 V2 原始 ambiguity.description 和修改原稿的操作说明。已通过 Kernel 不能替代人工确认原稿与 MathIR 语义一致；仍然保持 semanticAlignmentKernelProven=false。
- NativeFailureInspector 按 V2 的数据契约读取未完成步骤、解释警告和形式化记录，修复“0 与 1”“V2 已保存与暂无记录”的矛盾。
- 我的证明历史时间用当前时区中文格式展示，不改变内部 ISO 原值和排序。
