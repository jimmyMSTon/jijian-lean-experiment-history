# 极简 Lean Mac Native｜MathIR 结构失败诊断与原稿来源定位

日期：2026-10-15

## 真实问题

用户数列题双图盲测保存的一个真实 DeepSeek Flash MathIR 候选未通过确定性结构验证：多处量词复用同一 `d_m_rec` 绑定 ID，候选被标成 `MATHIR_V2_INVALID`（内层 `V2_BINDER_LEXICAL_REUSE`），因此没有 Lean/Kernel 结论；识别来源还有三处下标漏读，题目数域未声明却被模型默认写成 Real。

后端早已将失败候选保存为 `mathir_v2_draft`，并在已完成的 V2 job 错误中返回 `details.draftId`、`validationCode`、可选 `validationPath` 和 `validationSourceRefs`。旧 Native UI 虽显示错误类别，却未把实际保存的类型检查详情及来源区间反馈给用户，容易只看见抽象错误代码而不知道该向哪个原稿片段核对。

## 本轮仅修 Native

- 新增 `NativeV2StructureFailureEvidence.swift`：基于后端**保存的失败草稿**、该草稿身份及 `validationCode` 匹配关系，定位已有来源区间；按 Unicode code points 切分，不用 NSString UTF-16 偏移猜测；空位置、越界、重复 block ID、未知区块一律不提供伪位置。每个片段有块 ID 与 `[start,end)`，最多四条，单条最多 160 字符。未报告具体位置时诚实显示“不能可靠定位”。
- 对 `V2_BINDER_LEXICAL_REUSE` 和 `V2_SYMBOL_SCOPE` 给予非数学错误的中文归因，不以结构类型错误解释成用户证明错误，也不修改数学命题或将普通推理失败标成反例。
- NativeStore 在同一现存 V2 job 返回 `MATHIR_V2_INVALID` 后，凭 `draftId` **只 GET 一次本地 /api/artifacts/id**。这不重复 MathIR、识别、DeepSeek、Lean 或 Repair 请求。恢复候选前后检查原稿的 `documentRevision`、文字、`sourceKey`、当前错误码及 draft ID；若等待期间换图、编辑或改笔迹，旧候选无法附加到当前状态。
- `fail`、`newProof`、`editDraft`、图片导入与手写失效等生命周期清理候选错误证据；草稿只用于故障说明，绝不混入 `ProofRecord` 的数学核验判定。
- NativeSystemError 展示实际来源片段与 MathIR 校验路径，允许阅读和修订原稿；不自动重新验证同一无效 MathIR，也不把 Kernel 未运行当做数学证明被否决。
- 没有改变后端源码、MathIR Schema、证书/Proof Lock、正式模型配置或用户保存的历史。

## 实测

- Swift 编译实际 `BackendClient.swift`、错误证据提取模块及 `tests/native_v2_structure_failure_evidence.swift` 为可执行文件：PASS。验证 Unicode（开头为 emoji 的原文）、重复块、未知块和越界位置均不会误映射；当前真实样本的通用 binder 重用错误会得到专门说明，没有编造步骤位置。
- 编译实际 `NativeStore` 及全部相关 Native SwiftUI 源码，使用本地隔离 HTTP mock 模拟 `POST /api/v2/jobs` 两次（不访问 Provider），失败状态后只读读取 `mathir_v2_draft` 两次；第一份正确恢复来源 `x≤y`，第二份人为延迟草稿 HTTP 返回后，用户编辑新原稿，旧诊断无法附着。PASS；2 job POST、2 local artifact GET、0 DeepSeek。
- 此工作树非实时 Python pytest：609 passed、41 deselected，0 failed，仅既有 Starlette/AnyIO warning。
- 旧 Native 异步图像输入/编辑 revision race 回归、签名 App 构建验收，继续以具体测试输出为准，不提前宣称完成。

## 仍需要 Codex

本轮只修**失败结构的正确呈现**，不使错误的 MathIR 通过。通用数学后端仍需改善不能指定的数列值域语义、量词变量唯一绑定以及强归纳从原文到 MathIR 的可靠性；在修好真正的结构原因前不可把此用户样本标为 verified。用户真实图片不重复付费识别，已保存的失败候选足以复现 Native 的故障反馈。
