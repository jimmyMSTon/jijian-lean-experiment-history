# MathIR V2：初等数学通用词汇扩展与分层验收（2026-10-14）

## 问题来源

用户真实数列证明暴露 MathIR 此前只表达基本标量、多项式及有限和，缺少一般函数、索引、集合及常见初等数学运算。Codex 已独立提交 `a4896b5`，新增 Function(domain,codomain)、apply(f,x) 及实际 Lean/Kernel 单测。本分支在该函数基础上扩展严格的、可组合的初等数学表达；**不是**围绕具体数列 `a_n=n²` 增加特判。

## 实现范围

新增 `backend/v2/elementary_ops.py`，在同一处维护操作 arity、严格类型推断、Lean expression lowering，避免 Prompt、Schema、类型器和 Compiler 各写各的互相漂移。新增类型 `Prop`、`Set[T]`、`Finset[T]`（递归显式 element），保留旧 Nat/Int/Rat/Real、Polynomial、Function。扩展类型规则同步写入 MathIRV2 与 StructureOnlyMathIRV2 两份 JSON Schema。

覆盖 42 个独立表达案例，运算领域包括：
- 整数数论：Nat/Int 的 mod、整除、自然数 gcd/lcm、组合数 choose、互素、阶乘、素数、偶数、奇数、整数绝对值。
- 数值/实分析初阶：min/max、绝对值、sqrt/exp/log/tan、整数 floor/ceil。
- 函数组合：具有严格 domain/codomain 约束的 compose。
- 集合：成员/包含、并/交/差/补、空集/全集/单元素集合/插入、像和原像、有限/无限谓词。
- 有限集：成员、势、空集、有限求和/有限求积。
- 带 Nat 范围的有限积 `finite_prod`，与 `finite_sum` 一致强制 binder、上下界和端点类型；上下界原样保留，不添加隐含范围条件。

模型如对集合元素类型、序列值域没有来源依据，不能默认特定类型；表达式非法、类型不匹配、缺失数学绑定时明确拒绝，不能为使 Lean 通过而改变原稿语义。

## 额外发现的通用 Compiler 错误

扩展集合、函数后，现有证明组合器曾对不参与目标的多余参数一律写 `(0 : T)`。该技巧只适用于数值及少数类型，在 Set、Finset、Function、Prop 下并非合法 Lean 占位项，会令正确证明的 Kernel 检查失败。

本分支将普通路线与归纳路线共四处改为通用、确定性的 `_closed_inhabitant(T)`：数值/多项式取 0，集合/有限集取空集，函数取常值函数，命题取 True。使用前仍要求该参数与目标无关且没有来源声明约束；全部实例必须经过实际 Lean elaboration 和独立 Kernel replay。不会以占位项替代学生已写出的相关前提。
