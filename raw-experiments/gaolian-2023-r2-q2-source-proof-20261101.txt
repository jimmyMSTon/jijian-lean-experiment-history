【2023年全国高中数学联赛二试 A 卷第2题】
称正整数 n 为“好数”，如果对任意正整数 m≠n，都有
{2^m/n²}≠{2^n/m²}，
其中 {x} 表示实数 x 的小数部分。
证明：存在无穷多个两两互素的合数，且它们都是好数。

【证明】
先证明一个引理：若 n>1 为奇数，且 2 在模 n 下的乘法阶 ord_n(2) 为偶数，则 n 是好数。

反设 n 不是好数，则存在正整数 m≠n，使
{2^m/n²}={2^n/m²}。
两个有理数的小数部分相等，等价于它们的差是整数。因为 n 为奇数，分数 2^m/n² 已经约分，其最简分母为 n²。因此分数 2^n/m² 约分后的最简分母也必须是 n²。

写 m=2^t q，其中 t≥0 且 q 为奇数。分数 2^n/m² 约分后的分母为
2^{2t−min(2t,n)}q²。
它等于奇数 n²，故 min(2t,n)=2t 且 q=n。因此 m=2^t n。又 m≠n，故 t≥1。

由两个小数部分相等，差为整数：
(2^m/n²)−(2^n/m²)∈ℤ。
代入 m=2^t n 并通分，得到
2^{2t}n² | 2^{m+2t}−2^n。
特别地，模 n 有 2^{m+2t}≡2^n。由于 n 为奇数，2 与 n 互素，故
2^{m+2t−n}≡1 (mod n)。
令 d=ord_n(2)。由乘法阶的定义，d 整除 m+2t−n。但 m=2^t n 为偶数，2t 为偶数，n 为奇数，所以 m+2t−n 是奇数；这与 d 为偶数矛盾。引理得证。

现在令 F_k=2^{2^k}+1（k≥0）为 Fermat 数，并取 n_k=F_k²。显然每个 n_k 都是奇数且大于 1，并且是合数。

因为 2^{2^k}≡−1 (mod F_k)，所以 2^{2^{k+1}}≡1 (mod F_k)，而 2^{2^k} 不同余于 1。由于 2^{k+1} 的所有正因数都是 2 的幂，得到
ord_{F_k}(2)=2^{k+1}。
若 2^r≡1 (mod F_k²)，则也有 2^r≡1 (mod F_k)，故 ord_{F_k}(2) 整除 ord_{F_k²}(2)。因此 ord_{n_k}(2)=ord_{F_k²}(2) 是偶数。由前述引理，n_k=F_k² 是好数。

最后证明这些合数两两互素。若 i<j，则
2^{2^i}≡−1 (mod F_i)，从而
2^{2^j}=(2^{2^i})^{2^{j−i}}≡1 (mod F_i)，
因为 2^{j−i} 为偶数。因此 F_j=2^{2^j}+1≡2 (mod F_i)。又 F_i 为奇数，故 gcd(F_i,F_j)=gcd(F_i,2)=1。于是 gcd(F_i²,F_j²)=1。

因此 n_k=F_k²（k≥0）构成无穷多个两两互素的合数，并且每个都是好数。命题得证。
