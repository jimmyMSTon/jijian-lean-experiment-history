# 正式 App 实际可用性修复（2026-10-09）

## 范围

本次只修复 SwiftUI 客户端的任务进度与历史加载反馈，没有改动 DeepSeek Provider、MathIR、Statement Lock、Binder Map、Mathlib Retriever、Lean Runner、Repair Pipeline 或 Kernel Verification。此前已有的 UI 预览 fixture 改动保持原样。

正式客户端入口为 `macos/Native/NativeApp.swift` 中的 `NativeRoot`，由 `scripts/build_mac.py` 编译 `macos/Native/*.swift`。该正式入口使用 SwiftUI；`macos/App.swift` 中的旧 WKWebView 代码不在正式构建的源文件列表内。Stitch 导出不是运行时页面。

## 实际发现与修改

- 真实任务执行期间，服务端 job 已进入 `formalizing` / `verifying`，窗口仍停留在“正在准备证明”。在 `NativeStore.observe` 中加入只读 `/api/jobs/{id}` 阶段轮询，与现有 SSE 结果处理并行；它只读取任务状态，不会重新提交 AI 请求。任务结束、取消、错误或 App 停止时会取消轮询。
- 打开“我的证明”时，历史 API 和关联形式化记录需要异步读取，原界面没有立即显示加载反馈。现在先展示历史面板和“正在读取历史记录…”，完成后显示既有记录、空状态或统一错误文案。

修改位置：[NativeStore.swift](../macos/Native/NativeStore.swift)、[NativePages.swift](../macos/Native/NativePages.swift)。
