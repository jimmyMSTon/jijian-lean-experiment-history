# MathIR V3 通用数学主体建设实证

2026-10-17，独立分支 `codex/v3-general-math-bigbuild`。实现提交：`631407c`、`8977e5e`。本次直接修改后端、契约和测试，完成多领域共用表达与原步骤组合机制，并执行真实 Lean/独立 Kernel。本报告不宣称工单列出的全部数学领域或证明方法已覆盖。

## 实际实现

1. **匿名函数**：`lambda` 支持嵌套、高阶参数、命题值函数及依赖结果类型；接通显式词法声明、来源规范化、依赖闭包、类型推断、替换、编译和 Schema。局部变量不变成任意额外 theorem 参数，声明式 constraints 不隐式变成函数前提。
2. **条件值**：`ite` 检查命题条件及同类型分支，下放为使用显式经典判定实例的 Lean 条件项；条件不会升级为 theorem 假设。
3. **结构对象的显式视图转换**：`coerce` 请求 Lean 已注册 coercion，支持线性映射到函数、子模/理想到集合的组合。它不是任意转换函数或数值截断；不存在的 coercion 由真实 elaboration 拒绝。
4. **常量显式类型实参**：`MathlibConstantReference.typeArguments` 表示显式前置类型参数，接通来源、自由符号、作用域、捕获检测、代入和类型变量收集。真实 `RingHom.id ℝ` 与 `TypeApplication.argumentOrder` 共同表达当前 Mathlib 的 `LinearMap (RingHom.id ℝ) ℝ ℝ`，没有用错误的 `LinearMap ℝ ℝ ℝ` 冒充。
5. **完整引理的原步骤依赖**：`closedDependencies` 是 `dependsOn` 的受检子集。依赖类型取自被引用 claim 的实际完整 `expectedType`；变量、局部条件和依赖全部保持绑定。组合器使用其已核验的完整证明，不把局部假设当全局已知。普通依赖语义保留，归纳基例/步/辅助 claim 的相应通路也已接入。
6. **通用类型修复**：统一 `MathType(Prop)` 与内部 `Prop`；库函数返回的参数化对象只随该表达式传播，不全局注册为来源类型；代入检测表达式/Pi 中的自由变量捕获并拒绝不安全代入；类型等价键区分有限区间端点语义。
7. **锁与真实业务合同**：同步 Pydantic、两份 Schema、结构化提示、`prompt_source.py`、proof-only/repair payload、验证 step 元数据。闭合依赖参与 MathIR/route/ProofLock 身份；空默认字段省略，保留旧引用及旧路线的 canonical 哈希兼容。证明内容仍是唯一可修复部分。

8. **定义展开与依赖审计修复**：保守识别平坦的生成证明 `intro / dsimp / intro` 前缀，以已存在的 let binder 显式引入替代展开包装；独立检查候选及所有依赖使用后才应用。原文、既有原证明、类型和依赖图均受锁保护。

这些是通用机制，没有为每个领域新增一套专用流水线或数学类型白名单。常量名和模型填写的签名仍只是请求；真实名称、实例和签名以当前 Lean elaboration 为准。

## 实测揭示并处理的问题

- 初次环境检查没有找到 Lake，8 项被跳过，未计为通过；随后显式使用现有固定工具链，并保留 runtime attestation。
- 自行编写的初始概率样例错误地把任意测度上的常量方差视作零，已撤回该错误样例；改用原文单独明确的、Mathlib 对一般测度成立的缩放命题，没有给错误样例偷偷添加概率测度前提。
- 当前 Mathlib 集合谓词构造器为 `Set.ofPred`；错误的 `Set.setOf` 引用未通过，修正实际库名后通过。
- 导数公式曾因 Mathlib 实例路径/函数形式匹配失败；按真实 Lean 诊断使用 `.fun_pow` 与 `using!` 匹配，数学目标未变。
- `LinearMap ℝ ℝ ℝ` 在本机 Mathlib 明确不是正确类型；补足真正的环同态值实参与常量显式类型实参后通过。
- 库函数返回 `Submodule` 曾被静态层错误要求先单独声明；现在只传播已检查函数签名的结果类型，仍拒绝无来源的独立 TypeApplication。

## 明确缺口

- 这不是 Mathlib 全库反射。静态层没有完整推导所有实例及声明参数；真实 elaboration 仍是实际存在性和类型检查证据。任意 named implicit 参数及任意交错的常量级 type/term 参数尚没有完整接口，显式前置类型实参和普通值 apply 不能冒充全部依赖 elaboration。
- 一条 route 多项任意嵌套结构归纳、任意归纳类型 recursor、完整 proof-plan AST 尚未实现；本次闭合引理机制和现有 Nat/强归纳可复用，但不等于所有证明方法已结构化。
- 概率条件分布、条件概率、期望/方差的可测可积前提体系与 term-valued 实例证据没有整体验收。绝不从“有 Measure 类型”推断概率测度、非零条件概率或独立性。
- 欧氏角、仿射几何、圆、平行垂直的完整退化条件，线性代数的谱/基/维数/商空间，以及群作用/商环等没有在本次做全面 Kernel 代表性验证。已有开放表达入口与实际测试范围严格分开。
- 没有完成全历史 Lean 专项或所有领域的真实 DeepSeek 测试，没有做 OCR/图像语义盲测。语义忠实仍需保留来源、歧义及原步骤映射，不能由本报告证书取代。

对其他复杂 elaboration 包装，依赖审计仍可能返回未完成；本次仅实现并核验上述保守前缀修复，不会静默放宽 audit。
