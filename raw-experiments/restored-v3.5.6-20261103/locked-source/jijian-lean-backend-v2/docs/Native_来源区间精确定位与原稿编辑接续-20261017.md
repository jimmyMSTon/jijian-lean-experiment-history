# 极简 Lean｜Native 来源区间精确定位与原稿编辑接续

日期：2026-10-17。基线为 Native 分支 479f5ba；全部代码实施于独立工作树 codex/native-math-document-engine，避免触碰 Codex 当前正在扩建的 MathIR/Compiler/TypeChecker。以下为实际功能建设记录，而非发布标准或新产品限制。

## 客户端真实缺口

此前原稿对应页面通过 sourceRefs.blockId 直接高亮整块转录文字，不能可靠呈现一个步骤引用的精确公式片段；部分历史记录的 sourceRefs 混合有效与无效时，SourceFragments 会把剩余部分误认成完整原文。步骤详情打开图片时，首次匹配某个 blockId 可能导致重复标识历史对应到任意原图。编辑按钮虽然进入原稿编辑页，但无法把光标定位到该步骤来源区间。新增 MathIR V3 Function.binderId 依赖函数类型尚可能被误显示为普通 Function arrow。

## 本轮实现的跨层客户端功能

- 新增 NativeProofSourceIndex.swift：纯存储来源的 SourceRef 索引，读取全部 Unicode scalar 区间；拒绝缺失/重复来源块 ID、空引用、越界、无效区间，以及拆开一个组合 Emoji 或 Unicode 组合字符的可视高亮。所有步骤来源引用必须完整有效才标记为可靠定位；不拿单个有效子片段冒充完整来源。跨块、多页、多张原图及多个不连续来源区间均支持；交叠区间合并显示，原引用顺序和图片来源顺序分别保留。
- 新增 NativeProofSourceEvidence.swift：SwiftUI 人类可读的来源区间高亮，展示上下文、准确被引用文字和对应页数；明确区分转录文字区间和图片笔画坐标，未声称 OCR 图像像素级位置。NativeSourceMapping 的原稿列表改为精确高亮并使用 LazyVStack 承载多片段历史；NativeStepDetail 直接显示引用区间，可从真实唯一来源块关联多张原图。
- 修正 BackendClient.sourceFragments：V1/V2 已存证明原文对应实行多 SourceRef 全部有效才展示，不能静默省略异常引用；并检查 Unicode 组合字符边界。改动只影响来源的可读展示，不改变 MathIR/Lean/Kernel 判定。
- 新增 NativeManuscriptSourceSelection.swift：当编辑器当前文字与保存来源块按合同拼接后完全一致、所有 SourceRef 均可靠时，把第一处原稿步骤来源转换成 AppKit UTF-16 精确选区；文本不完全一致、来源块重复、跨图非文本方式无法安全确定位置时绝不猜测。选区焦点命令一次性使用，防止 SwiftUI 重新挂载或用户修改内容后重新跳到旧位置。
- NativeEditing 与 NativeDraftEditor 已接入选区定位。在修改证明页选择任一已存步骤时，可以自动定位到该步骤在当前可编辑原稿中的真实文字位置；不会修改数学内容、添加前提或自动请求 AI。识别不匹配时用户仍可手动编辑，并看见来源不一致提示。
- NativeMathIRContext 展示新增 V3 Function.binderId 的依赖函数 Π 类型，保持 Π 型值依赖和普通箭头类型之间的准确区别，同时兼容现有 mathlib_const 文本标识。

## 验证证据与边界

- 新增真实 Swift 定向测试 native_proof_source_index.swift（跨来源、重叠引用、多页、组合 Unicode、无效记录 fail closed），native_manuscript_source_selection.swift（已存来源到光标、UTF-16、多文本段、过时来源、重复绑定拒绝）。原有 native_v2_claim_display.swift 增补 V1/V2 部分无效引用拒绝；native_v3_math_context.swift 增补依赖 Function/Π 型显示。测试通过，已纳入 scripts/check_native_math_document.py，与原数学排版、数学编辑器、AppKit 原生撤销/重做、复杂证明结构回归合计 8 组串行检查。
- 完整 macos/Native/*.swift 的 SwiftUI typecheck 通过。最终 whole-module-optimization 的完整 Mach-O 链接结果以实际任务回执为准。
- 本轮不修改 Codex 的数学核心、DeepSeek Provider、AI 请求、ProofIR、Statement Lock、数学假设或 Lean Kernel。客户端正确定位保存的文本，不等于独立证明原图与转录的语义等价；完整 App GUI 用户验收按用户指定可待主体开发后进行。
- 当前所有变更先独立提交；Codex 当前后端工作树仍有活跃修改，安全合并与 App 安装应以其实际提交完成和现有本地构建脚本为依据。该过程不设新的‘正式版’发布门槛。
