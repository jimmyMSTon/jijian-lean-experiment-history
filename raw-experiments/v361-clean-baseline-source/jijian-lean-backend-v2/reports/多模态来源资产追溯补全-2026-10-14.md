# 多模态来源资产追溯补全（2026-10-14）

## 根因

V2 `SourceEvidence` 保留了识别文字块和块上的 `assetId`，但 `recognitionEvidence` 投影只保留歧义、修订和识别记录 ID。PDF 原始文档 ID、空白页渲染图及混合输入子项的对应关系因此会在 V2 结构后丢失。最终 `mathir_v2`、运行记录与可恢复 checkpoint 也没有继续传递这部分来源引用。

## 修改

- `recognitionEvidence.sourceAssets` 现在列出 `source_image`、`source_document`、`page_image` 引用；每条可带 `recognitionId`、混合输入 `partIndex`、PDF 页码和所覆盖的 `blockIds`。
- `referenceStatus: "id_preserved"` 只表示来源记录中的 ID 被保留，不声称当前资产文件仍可读取。没有来源 ID 时保持为空，不生成替代 ID。
- PDF 页清单即使对应空白页也保留；旧记录在 `sourcePdfAssetId` 顶层字段中的原 PDF 引用会迁移进来源证据；混合 PDF 页块映射到父级稳定 block ID。
- 清单会穿过结构 artifact、最终 `mathir_v2` artifact、`mathir_v2_run`、阶段 checkpoint、checkpoint HTTP 恢复响应和 `mathir_v2_structured` 事件。
- `sourceAssets` 不发送给 MathIR 模型，不含图片字节或供应商原始 payload；MathIR、SourceRefs、Statement Lock、proof、Lean 与 Kernel 判定均未改变。

## 边界

本次确认后端能持久传递原图、PDF、页图和混合子项的资产引用，不代表文件系统当前可读取，也不代表 SourceRef 语义与图片内容等价。SourceRef 范围检查仍只验证 block ID 与 Unicode 区间；语义对齐仍未由 Kernel 证明。历史手写图像链已有多次真实视觉请求但中断，另一次文本盲测以 `V2_BINDER_UNKNOWN` 结束；均没有这张图的最终 MathIR/Lean/Kernel 结果。本轮没有重复视觉请求。SwiftUI 历史/原稿查看尚由 ChatGPT 侧验收，本轮未修改原生客户端。
