## 本轮发现与修复

既有 NativeStore.editDraft 在自由文本修改时，立即清空 recognition 和 importedParts，但没有提示曾关联图片/手写的验证将变为文字验证。已有历史恢复代码负责从不可变 recognition snapshot 读取已存视觉来源；后续主动修改文字不能再暗中将新的文字称为已经视觉确认的旧图。

- NativeV2HistorySource.freeTextEditSourceNotice 根据当前识别块、混合导入 recognition ID 或前一个保存的 proof source asset ID 判断是否需要来源变更提示。
- NativeStore.editDraft 在清空当前识别关联前捕捉该提示，说明当前按修改文字验证、旧原图保留于历史。
- 原来的用户文字、原稿存档、Kernel 判定、ProofLock、DeepSeek/Mathlib 提交流程全部保持不变。
- Swift 单测涵盖当前图片、混合识别和打开历史而识别快照为空的三种场景；常规纯文本不产生误提示。
