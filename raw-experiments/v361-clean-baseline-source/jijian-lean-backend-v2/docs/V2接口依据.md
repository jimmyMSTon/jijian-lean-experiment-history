# V2 接口依据

核对日期：2026-10-06。这里只记录本补丁使用的外部协议依据，不冻结供应商未来政策，也不把示例数字设为产品限额。

- DeepSeek V4.1 Flash 官方发布说明：https://www.deepseek.com/en/news/deepseek-v4-1-flash/
  当前推荐 API 名称 `deepseek-flash`；旧 `deepseek-v4-flash` 是兼容路由。
- DeepSeek Vision：https://api-docs.deepseek.com/guides/vision/
  支持用户消息中的图片；Chat Completions 使用 `image_url`，可发 Base64 data URL。
- DeepSeek JSON 输出：https://api-docs.deepseek.com/guides/json_mode/
  使用 JSON 对象输出；本补丁另外做本地结构校验，不宣称 json_object 等同于强制 Schema。
- DeepSeek 思考模式：https://api-docs.deepseek.com/guides/thinking_mode/
  显式 `thinking.type` 只在实际配置时发送。
- Lean 语言参考：https://lean-lang.org/doc/reference/latest/
  `#check` 用于查询表达式/声明类型。本补丁沿用原工具链版本，通过实际运行查询，而非联网文档猜库版本。
- pypdfium2 Python API：https://pypdfium2.readthedocs.io/en/stable/python_api.html
  用于本机 PDF 页面渲染，不执行 OCR；其底层 PDFium 访问按文档要求串行化。

本补丁没有使用 OpenAI、Mathpix、PaddleOCR 的生产 API，也没有“调用失败自动换服务”的分支。
