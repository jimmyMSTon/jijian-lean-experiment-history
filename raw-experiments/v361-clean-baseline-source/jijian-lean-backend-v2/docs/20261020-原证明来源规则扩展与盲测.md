## 1. 本轮核心实现

### 1.1 多步代数证明

- 从原始中文证明读取完整相邻等式链。例如 `u²+v²=12²−2×35=144−70=74`，验证其每一段与**相应 MathIR 节点的原始文字和数学表达式**匹配。
- 避免只做稀疏多项式规范化后因中间表达式均等于同一常数而任意挑两段传递，遗漏第三个已声明步骤，导致真实正确原稿 5/6 假阴性。
- 不能忽略用户额外声明的前提或“因为”的无关数学句。反例包括改错相邻等式、偷添依赖、真结论但因无关等式而断言。

### 1.2 整数整除及存在见证

- 严格对应用户写出的整除定义、`∃k:ℤ`、局部“取这样的 k”、其下的等式平方、`k²` 为整数、`m²` 为已证数的整数倍、存在消去闭合。
- 同一可见名称可在量词与局部分支中不同 ID，但仅在独立来源、局部语义和 Lean scope 一致时认证；不据此默许类型变化。
- Typing-only 节点不是 Lean 可证明的独立数学主张，编译器在 proof obligation 中会省略它，但独立来源审计**仍须证明该 typing 节点及来源确实存在**，不能跳过。
- 来源覆盖检查允许“因为 7 整除 t”只在数字 7 起始建立 SourceRef，但“因为”后到有来源证明式之间只能出现空白；无关理由与没标记的中间数学声明仍会被拒绝。

### 1.3 高等数学 `ε-N` 极限平移

- 现有 `Filter.Tendsto` 形式化保持 Lean/Mathlib 为唯一形式数学判定者。
- MathIR 可能省略全称引入节点对先前局部假设的依赖，导致原本正确的“选取 K，则对所有 n≥K ...”出现不可证明的固定局部 proof obligation。新增确定性闭合作用域转换，仅将**当前父 scope 的原稿已有 local_assumption**，且是已关闭子证明的可核对依赖祖先、来源早于结论的节点提升为本节点依赖；不新造定理前提、不修改用户源文本或补写 Lean 证明，变化完整留痕。
- 自动修复走真实 DeepSeek Proof-only / Repair / Lean4 Kernel，再经独立来源审计。来源检查必须核对真正的序列类型 `ℕ→ℝ`、原文独立读取的下标/ε/界指标名称、正误差、量词、上下界、平移绝对值等式、复用界指标和极限定义。不能把数学上相同的 AI 另证直接算成学生来源。
- 测试覆盖不同数学变量和文字别名，包括模型命名的 `n_lim`、`K_exists` 和用户原文的 `n`、`K` 之间的唯一数学作用域联系。当前这些规则只认证结构能独立确认的原稿类别，其他自然语言继续返回未认证，不宣称支持任意高等证明。
