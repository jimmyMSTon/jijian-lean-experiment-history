# 极简 Lean｜Native 长证明、历史、核验报告一体化主体扩建

日期：2026-10-17。开发自已完成的 Native 数学文档、数学编辑与原稿精确来源功能分支。此次一次性集中补齐长证明阅读导航、历史浏览、核验报告导出、长文本公式解析复用和跨页面滚动。

## 已实现功能

**长证明阅读**：新增 NativeProofReadingIndex + NativeProofReadingNavigator。依据保存的真实 ProofRecord 逐步核验结果组织步骤，支持中文和数学式（可忽略空格差异）搜索、全部/已核验/未核验/原文待核对分类、步骤序号、证明路线、依赖、SourceRefs 状态、当前焦点与上一步/下一步/下一个未核验步骤。长证明列表为 LazyVStack；主工作区证明卡片支持 ScrollViewReader 按步骤复合 ID 跳转，结果和步骤详情共用同一导航信息。只选择已保存原证明步骤，不请求新的 MathIR，不自动修改证明或认定数学错误。

**历史浏览**：新增 NativeHistoryReadingIndex + NativeHistoryBrowser，支持标题/状态/日期本地搜索、按明确 Kernel 记录与来源核对信息筛选、稳定时间排序（时区偏移按实际 Date 而非 ISO 字符排序）、LazyVStack 和异步打开状态。V1/V2 历史元数据明确保存 kernelVerified、步骤计数；缺少证据不推断成功。仍读取已保存 artifacts；刷新失败保留独立历史错误提示。

**核验报告**：新增 NativeProofReport + NativeProofReportExport，用户主动从结果页、工作台或菜单导出 Markdown 及多页、可搜索、可选择文字的 A4 PDF。报告分列原稿转录文字、原命题、路线、逐步状态、实际 Lean 目标、来源位置、前序依赖、来源语义未确认警告；不利用 Kernel 证书冒充图片/自然语言原稿语义等价，不调用 DeepSeek、Lean 或 Repair。报告严格使用保存的证据；不生成新数学证明。Markdown 数学原文以安全动态围栏保留，PDF 使用 AppKit/CoreText/CGContext 的原生多页文字排版与分页，不引入 WebView、远程服务。

**性能及一致性**：NativeMathDocumentCache 使用有内存限制的 NSCache 对完全相同的原文只读 TeX AST 复用，原稿修改后自动使用不同缓存键，避免长证明滚动/重绘期间反复解析同一公式。切换保存记录时 NativeStore.presentProofRecord 清理上一份证明的步骤选择并选择当前证据里的第一项待核验步骤；不影响旧证明的状态判定。步骤选中和跨页面返回时，滚动定位到当前记录真实步骤。历史大量行使用 LazyVStack。

## 验证

- scripts/check_native_math_document.py 既有 8 组真实 Swift/AppKit 回归（数学文档、ProofRoute、原稿编辑、撤销/重做、原文来源、π 类型等），新加第 9 组 NativeProofReadingIndex/NativeHistoryReadingIndex/NativeProofReport/NativeProofPDFRenderer 和 PDFKit 检查。
- PDFKit 实际加载导出的 PDF，证实 PDF 页、文本可搜索、120 步长证明多页分页且末步未丢失；核验报告失败状态/原稿核对警告受测试保护。历史时间排序跨不同时区经过确定性验证。
- 全 macos/Native/*.swift 联合 typecheck 与 whole-module-optimization 链接、Git 提交/整合以及 App 安装状态需以最新工具实际执行回执注明，不能把源码功能代码或单体回归冒充用户 GUI 通过。

## 可信边界与并行

这次属于用户已授权的 Mac 功能建设，不新增证明范围白名单、额度限制、审批环节、供应商切换、人工 Gate 或数学默认前提。Codex 独立负责 MathIR/TypeChecker/Compiler/Mathlib/Lean/Kernel 的广泛数学核心扩建；Native 工作树不改动它的活跃未提交文件。产品是持续更新的开发版本；代码稳定后即可安全合并并从最新 main 构建安装，无单独所谓正式版门槛。
