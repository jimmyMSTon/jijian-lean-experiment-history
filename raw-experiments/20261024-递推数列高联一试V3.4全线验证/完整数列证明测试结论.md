测试日：2026-10-24；自拟高联一试中档题，不声称历年官方竞赛真题。

## 题目与数学结论
对实数数列 $a_1=1$、$a_{n+1}=(3a_n+2)/(a_n+2)$（$n\ge1$），求证
$$ a_n=\frac{2(4^n-1)}{4^n+2}. $$
原稿为 5 段完整论证：先归纳证明 $0<a_n<2$；引入 $b_n=(2-a_n)/(a_n+1)$；推得 $b_{n+1}=b_n/4$；归纳 $b_n=2/4^n$；整理回代通项，检验首项。所有实际原文保留于相邻上级路径 `../20261024-数列分式递推陌生题原稿.txt`。

## 因测试发现的通用工程修复
- 真实已检验：`backend/lean/runner.py` 在 Kernel 验证之后，对巨大嵌套 JSON wire evidence 根据 JSON **编码字节数**做 32 KiB 的边界判断，超额证据只返回不可变证书的 SHA-256 和原始字节数及省略理由，不改变 Lean 的 source proofTerm 或 Kernel Certificate。
- 同一数列题已保存的原证明再次走**独立真实 Lean Kernel**，得到 `checked=true`、`statementMatched=true`、无额外公理，并将返回体从数十 MB 缩减至 **37,941 bytes**。证明 SHA-256 与省略记录一致；本次回放不调用 DeepSeek，不算新的 AI 泛化样本。
- 新的补丁安装、构建与全项目回归必须另行记录，旧 V3.4 的巨型验证记录不以任何方式覆盖或伪造为原始完整响应已成功。

## 产品判断
该数列原证明的整篇形式化证明核验成功，是比简单代数更加复杂的一次真实通用测试。**但自然语言语义忠实性没有形式认证；整轮用户交付受过大 Lean evidence 导致的 API 超时影响。** 修补后，需继续保证正式 UI/反馈通路性能，不得仅因内核正确就宣称用户侧全线无缺陷。
